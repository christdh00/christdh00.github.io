## Publish on GitHub Pages

1. Create a public repository named `christdh00.github.io` (assuming you want to publish under your `christdh00` GitHub account).
2. Upload **all files from inside this folder** to the repository root: `index.html`, `styles.css`, `script.js`, `favicon.svg`, and `.nojekyll`.
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Visit `https://christdh00.github.io/` when GitHub Pages finishes deploying.

**Privacy:** Publishing to a public GitHub repository makes the files and the displayed information available to everyone. Only publish what you're comfortable making public.
